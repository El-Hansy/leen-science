# Leen Science — تطبيق ويب للمذاكرة والاختبارات 🔬

تطبيق ويب (يفتح في أي متصفح) مبني على منهج الساينس للصف الرابع.
الفكرة زي **IXL**: الطالب يذاكر الدرس، بعدين يتدرّب على أسئلة، ودرجته (SmartScore)
بتزيد لما يجاوب صح وتقل لما يغلط، لحد ما توصل ١٠٠ ويتقن المهارة.

---

## طريقة التشغيل

**أسهل طريقة:** دوس مرتين على `start-server.command` — هيفتح التطبيق في المتصفح لوحده.

أو افتحي `index.html` بالضغط عليه مرتين مباشرة. الطريقتين شغالين من غير إنترنت،
بس طريقة الـ server بتضمن إن التقدم والنجوم تتحفظ بشكل أكيد.

> التقدم والنجوم بتتحفظ داخل المتصفح نفسه (localStorage)، يعني لازم نفس المتصفح
> على نفس الجهاز عشان التقدم يفضل موجود.

---

## الأقسام الموجودة

| القسم | الوظيفة |
|---|---|
| 📖 **Learn** | شرح الدرس كامل بالإنجليزي بالصور المأخوذة من الملزمة (الترجمة بزر ⓘ) |
| 🃏 **Flashcards** | كروت للمصطلحات — وش: الكلمة، ضهر: التعريف (والترجمة بزر ⓘ) |
| 🎯 **Practice** | تدريب مستمر بتصحيح فوري وشرح بعد كل سؤال + SmartScore من ١٠٠ |
| 📝 **Quiz** | اختبار محدد (١٥ سؤال للدرس / ٢٥ للموضوع كله) بدرجة ومراجعة لكل سؤال |
| 🩹 **Fix my mistakes** | يجمع الأسئلة اللي غلطت فيها قبل كده ويعيدها لحد ما تتظبط |

**اختصارات لوحة المفاتيح:** أرقام `1`–`4` لاختيار الإجابة · `T` / `F` لصح وخطأ · `Enter` للسؤال التالي.

**أنواع الأسئلة:** اختيار من متعدد · صح وخطأ · أكمل من البنك · اكتب المصطلح العلمي ·
رتّب الخطوات · وصّل · سمِّ أجزاء الرسم · أجب بأسلوبك (تصحيح بالكلمات المفتاحية).

## اللغة — إنجليزي بالكامل، والعربي عند الطلب فقط

الملزمة إنجليزي، فالتطبيق كله (الشرح والأسئلة والاختبارات والنتيجة) **إنجليزي فقط**
زي الامتحان بالظبط — عشان لين تتعود على صياغة الأسئلة الحقيقية.

الترجمة العربية موجودة لكنها **مخفية**، وتظهر بطريقتين:

| الطريقة | النتيجة |
|---|---|
| زر **ⓘ** الصغير في ركن أي بطاقة أو سؤال | يترجم **هذه البطاقة فقط** — للأب أو الأم لو احتاجوا يفهّموها كلمة أو جملة |
| زر **`ع`** في الشريط العلوي | يفتح **كل** الترجمات في الصفحة دفعة واحدة |

زر الـ ⓘ موجود على: بطاقات الشرح · المصطلحات · جدول المقارنة · كروت الفلاش ·
نص كل سؤال · صندوق التصحيح بعد الإجابة.

**باقي أزرار الشريط العلوي:** ⭐ النجوم · 🔊 الصوت · 🌙 الوضع الليلي.

---

## إضافة ملزمة جديدة

1. ابعتلي ملف الـ PDF وأنا أحوّله لملف محتوى.
2. الملف بيتحط في `content/` باسم جديد مثلًا `content/topic5.js`.
3. يتضاف سطر واحد في `index.html` تحت التعليق `content packs`:

```html
<script src="content/topic5.js"></script>
```

خلاص — الموضوع الجديد هيظهر لوحده في الصفحة الرئيسية بتقدمه ودرجاته.

## شكل ملف المحتوى

```js
SC.registerTopic({
  id: 'gr4-t5',                 // لازم يكون فريد
  title: 'Topic 5 · ...', titleAr: '...',
  grade: 'Grade 4', term: '1st Term',
  cover: 'assets/xxx.png',
  lessons: [{
    id: 'l1', num: 1, title: '...', titleAr: '...', blurb: '...', blurbAr: '...',
    cards:    [ /* شرح الدرس */ ],
    glossary: [ /* كروت المصطلحات */ ],
    skills:   [ { id:'l1s1', title:'...', titleAr:'...', icon:'🎯', questions:[ /* الأسئلة */ ] } ]
  }]
});
```

### بطاقات الشرح (`cards`)
| النوع | الاستخدام |
|---|---|
| `{t:'hero', img, en, ar}` | صورة كبيرة + مقدمة |
| `{t:'heading', en, ar}` | عنوان قسم |
| `{t:'note', en, ar}` | ملاحظة/تعريف مهم |
| `{t:'bullets', items:[{en,ar}]}` | نقاط |
| `{t:'terms', items:[{term,termAr,img,def,defAr}]}` | كروت مصطلحات بصور |
| `{t:'image', img, caption, captionAr}` | صورة بتعليق |
| `{t:'compare', headers, headersAr, rows:[{k,kAr,a,aAr,b,bAr}]}` | جدول مقارنة |

### أنواع الأسئلة (`questions`)
```js
{t:'mcq',   q, qAr, img, choices:[...], a:2, ex, exAr}
{t:'tf',    q, qAr, a:true, ex, exAr}
{t:'fill',  q:'A ___ is ...', bank:[...], a:[['pattern']], anyOrder:false, ex, exAr}
{t:'term',  q, a:['cliff','cliffs'], bank:[...], ex, exAr}
{t:'order', q, items:[{id,img,label}], a:['s1','s2'], ex, exAr}
{t:'match', q, pairs:[{l,r}], ex, exAr}
{t:'label', q, img, bank:[...], points:[{id:'A', a:['humus']}], ex, exAr}
{t:'written', q, keys:[['weather','break'],['erosion']], model, modelAr}
```
`a` في `mcq` هو رقم الإجابة الصحيحة بادئًا من صفر · `ex` هو الشرح اللي بيظهر بعد الإجابة.
